TVCheck 2.0 — Windows 10/11 x64

БЫСТРЫЙ ЗАПУСК
1. Распакуйте весь TVCheck-Windows-x64.zip. Не запускайте EXE внутри архива.
2. Откройте TVCheck.exe из папки TVCheck. Python, MediaInfo и FFmpeg устанавливать не нужно.
3. Выберите профиль ТВ, файл/папку и USB либо DLNA. Нажмите «Проверить».
4. По умолчанию выполняется быстрая проверка характеристик MediaInfo. Измерение битрейта не запускается и не читает весь файл.
5. Включите «Битрейт · читать весь файл», только если нужны средний поток и пиковый битрейт. Для больших фильмов это может занять заметное время.
6. Выберите строку результата. «Подробнее →», двойной щелчок или Enter открывают окно с вкладками видео/звук, битрейт/доставка, субтитры.
7. Настройки → Оформление: Blue Day, Crimson Night, Green Cozy, Violet Neon, Sakura Red, Slate Blue. Выбор сохраняется между запусками.
По умолчанию DLNA/сеть отключён, поэтому основной экран работает только в режиме USB.
Включить её можно глобально через Настройки → Проверка совместимости по DLNA/сети. Это оценка файла для сетевого воспроизведения, а не управление DLNA-сервером.
Полосы прокрутки появляются только при необходимости. Колесо прокручивает список; Shift+колесо — по горизонтали.

УСТАНОВКА И ПКМ
Install.cmd копирует программу в %LOCALAPPDATA%\Programs\TVCheck,
создаёт ярлык в меню «Пуск» и пункт ПКМ с иконкой. Права администратора не нужны.
Можно не устанавливать: программа работает из распакованной папки.
Для переносной версии пункт ПКМ добавляется через Настройки → Добавить в ПКМ.
После этого не перемещайте папку программы; после переноса добавьте меню заново.
ПКМ доступно по папке, внутри папки и по файлу. В Windows 11 — также в «Показать дополнительные параметры».
Удаление: Uninstall.cmd или список установленных приложений Windows.
Пользовательские профили/настройки в %LOCALAPPDATA%\TVCheck сохраняются при удалении.
Windows SmartScreen может предупреждать о неподписанном EXE: сборка не имеет коммерческой цифровой подписи.

ЧТО ПРОВЕРЯЕТСЯ
- Контейнер и совместимость кодека именно внутри него.
- Все видео- и аудиодорожки, профиль/уровень, глубина цвета, цветность, разрешение, FPS.
- Ограничения аудио; совместимая альтернативная дорожка не делает весь файл «неподдерживаемым».
- Средний поток и наибольшая сумма размеров пакетов за фиксированные интервалы по 1 секунде.
- Отдельно пик каждой видеодорожки и суммарный поток видео + ВСЕ аудиодорожки (Σ).
- Время пика относительно начала файла. Накладные расходы контейнера/сети в Σ не входят.

ОК НЕ ЯВЛЯЕТСЯ ГАРАНТИЕЙ
Зелёный статус: выбранный режим соответствует профилю и полному измерению потока; отдельные неопасные пробелы MediaInfo показаны как справка в деталях.
Жёлтый: есть реальный риск — пик близок к пределу, доставка превышает указанную скорость, анализ неполный или сетевой режим нельзя подтвердить.
Красный: найдено несоответствие профилю видео/звука либо измеренный видеопик выше его лимита.
Ошибка: файл/источник прочитать не удалось.
Субтитры никогда не окрашивают общий результат в жёлтый: их особенности вынесены в справку.
Быстрая проверка без измерения пиков не выдаёт полный зелёный результат.

Секундный пик — не мгновенный и не скользящий максимум. Более короткие всплески могут быть выше.
Программа читает пакеты, но не декодирует все кадры: не гарантирует отсутствие повреждений,
ошибок прошивки, перегрева, медленной флешки, задержек NAS или несовместимых особенностей кодирования.
Если видео виснет даже при низких пиках, сравните другую флешку/USB-порт и другую копию файла;
проверьте целостность и попробуйте remux без перекодирования. Это диагностика, не установленная причина.
Конвертация и изменение исходных файлов НЕ выполняются.

USB И DLNA
Совместимость по USB не доказывает работу DLNA. Для сети показывается отдельная осторожная оценка.
MediaInfo/FFprobe не проверяют DLNA-сервер, MIME-тип, direct play, серверное транскодирование,
выбор дорожек и фактическую связь с ТВ. Отказ только DLNA сам по себе не доказывает высокий битрейт.
LG UK6300 поддерживает DTS по USB, но руководство ограничивает DTS для сетевого воспроизведения.
Настройки → Скорость носителя / сети: можно указать ИЗМЕРЕННУЮ устойчивую скорость в Мбит/с.
Пустое поле = неизвестно. 1 МБ/с = 8 Мбит/с. Программа не измеряет соединение с телевизором.
Предупреждение о запасе 15% к пределу кодека и 20% к скорости доставки — эвристика, не дополнительные лимиты LG.

ОФОРМЛЕНИЕ
Blue Day, Crimson Night, Green Cozy, Violet Neon, Sakura Red, Slate Blue.
Темы меняют палитру и декоративную иллюстрацию. Выбор сохраняется.

ДРУГИЕ ТЕЛЕВИЗОРЫ
Настройки → Профили телевизоров. Редактор позволяет добавить/импортировать JSON.
В комплекте только профиль LG UK6300PLB с ПО 05.50.70; чужие модели не выдумываются.
Новый шаблон копирует текущие ограничения, но помечен verified=false. Замените данные по руководству своего ТВ.
Смена одного названия НЕ делает ограничения подходящими новому телевизору.

Схема профиля v1 (пример: source/profiles/lg-uk6300.json):
- id: уникальная строка a-z, 0-9, _ и -, максимум 80 символов; lg-uk6300 защищён от перезаписи редактором.
- name, firmware: модель и ПО; sources: ссылки на документацию.
- verified: true только после сверки источников. false оставляет предупреждение.
- containers: объект, например mkv: {video: ["AVC", "HEVC"], audio: ["AAC", "AC-3"]}.
  Имена контейнеров: mkv, mp4, ts, avi, asf, 3gp, mpg, vob, rm, webm, ogg, flv.
- video_rules: объект по нормализованным именам кодеков (AVC, HEVC, VP9, AV1 и т. д.).
  profiles: допустимые имена до @L; bit_depths: числа; chroma: например ["4:2:0"].
  max_width, max_height, max_fps: численные пределы.
  max_level_fhd / max_level_uhd: уровни, например 4.2 / 5.1; null = не проверяется.
  max_mbps_fhd / max_mbps_uhd: предел видеопотока в Мбит/с; null = неизвестно, не ОК.
  FHD: ширина <=1920 и высота <=1080; иначе UHD.
- unsupported_video / unsupported_audio: явно неподдерживаемые кодеки.
  Для разрешения нового кодека уберите его из запрета, добавьте в containers и video_rules (для видео).
- uhd_containers / uhd_video / uhd_audio: отдельные сочетания из UHD-таблицы производителя.
- hdr_formats: заявленные HDR-форматы; options: dts_network, aac_main, gmc_qpel,
  dolby_vision, width_4096_uncertain. Булевы значения — true/false.

Сохранённые JSON: %LOCALAPPDATA%\TVCheck\profiles. Их можно перенести на другой ПК и импортировать.
Профили описывают проверяемый набор ограничений, а не эмулируют плеер любой марки.
Для новых специфических условий производителя может понадобиться расширение движка; исходники приложены.

ЗАВИСИМОСТИ
В tools находятся MediaInfo CLI 26.05 x64 и FFprobe 8.1.1 x64.
При запуске проверяется, что оба анализатора работают. Подключения к Интернету для работы не нужно.
Если проверка зависимостей не проходит, восстановите ПОЛНУЮ папку из архива, включая _internal и tools.
Не нужно указывать установленный графический MediaInfo: используется встроенный CLI.
Установленный MediaInfo.dll/CLI всё ещё можно указать через --mediainfo в командной строке.

КОМАНДНАЯ СТРОКА
TVCheck.exe --cli "D:\Movies" --json "D:\report.json"
TVCheck.exe --cli "D:\Movies\film.mkv" --mode network --link-mbps 70 --full
TVCheck.exe --cli "D:\Movies" --quick --no-recursive
TVCheck.exe --cli "D:\Movies" --profile my-tv
TVCheck.exe --check-deps
Коды выхода CLI: 0 — ОК; 1 — предупреждение; 2 — несовместимость;
3 — ошибка или пустой список; 130 — отмена. Не передавайте --cli для обычного окна.
